# Guided workflow and recovery contract

Updated 2026-09-05. Source implementation is complete; installation and real asset acceptance have separate evidence in `PROJECT_STATUS.md`.

The active creation workspace has one primary subject prompt. Generation category, style, scale, budgets and seed are optional settings with an effective-value summary. Finishing uses one instruction with optional settings; serial batch is collapsed until requested. The outer route planner collapses when the creation workspace opens.

Numbers remain raw text while being edited. Invalid seed, dimensions, budget or finish duration disables admission and yields an inline explanation. The main process revalidates the same constraints. A custom style must include a description. Unavailable providers cannot be selected as though ready; installation events refresh the currently selected provider.

Concept review retains exact image/report/spec bindings and all three existing pass conditions. One explicit comprehensive attestation can set the three checks together; detailed checks remain available. Geometry, material and motion inspection remain independent required stages. No progress, background task or technical check is a user's visual approval.

Known unsupported local motion transformations are rejected before authoring. Supported rotation must not conceal requested unfolding, splitting or melting. Negated actions remain negative, and `but`, `however` and `instead` begin contrasting clauses. Temporal `not yet` remains negative. This bounded guard complements visual acceptance; it is not a full semantic validator.

Saving permits one automatic attempt per approved finishing result. Concurrent saves are blocked. Current save verification errors take priority over a previous catalog entry and expose Retry save for the exact retained result. A saved draft error remains separate from a managed-asset copy error.

Update status is retained in the main process and available immediately after renderer reload. Checking, download and installation have separate valid states; duplicate operations are coalesced or rejected. Missing feed configuration skips network checks. Downloads and install require explicit actions, and install errors release the operation latch. Update IPC uses the main-window/top-frame sender guard.

Fleet probes abort after eight seconds and cancel unused response bodies. An HTML fallback on API/asset endpoints is a failed probe even with HTTP 200. Intentional UI endpoints and authentication reachability retain their declared meanings. Doctor JSON and text share exit criteria; an absent CLI login is a failure independently of healthy endpoints.

Regression entry points: `test:guided-reliability`, `test:prompted-animation`, `test:prompt3d-renderer-recovery`, `test:prompt3d-orchestrator`, `test:prompt3d-workflow`, and `smoke:packaged`. The packaged smoke uses an isolated offline profile and never generates an asset.
